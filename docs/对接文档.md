### 前端要调用的写函数

| # | 函数 | 参数 | 说明 |
|---|------|------|------|
| 1 | `buyTicket` | `uint256 roundId`, `uint256 numTickets`, `bytes32 referralCode` | 买票。ETH 轮次需 `{value: ticketPrice * numTickets}`；ERC-20 轮次需先 approve |
| 2 | `triggerDraw` | `uint256 roundId` | 轮次结束后**任何人可调用**，触发 VRF 抽奖（空池直接取消） |
| 3 | `retryDraw` | `uint256 roundId` | VRF 超时 (24h) 后重试 |
| 4 | `claimPrize` | `uint256 roundId` | 中奖者领取奖金 |
| 5 | `claimRefund` | `uint256 roundId` | 已取消轮次的退款 |

### 前端要读的 view 函数

| # | 函数 | 参数 | 返回 |
|---|------|------|------|
| 1 | `getRound` | `uint256 roundId` | `Round struct`（全量轮次信息） |
| 2 | `getWinners` | `uint256 roundId` | `address[] memory` |
| 3 | `getPayouts` | `uint256 roundId` | `uint256[] memory` |
| 4 | `canClaimPrize` | `uint256 roundId, address player` | `bool` |
| 5 | `isWinner` | `uint256 roundId, address player` | `bool` |
| 6 | `getTicketCount` | `uint256 roundId, address buyer` | `uint256` |
| 7 | `getUserTicketCount` | `uint256 roundId, address user` | `uint256` |
| 8 | `prizeClaimed` | `uint256 roundId, address winner` | `bool` |
| 9 | `currentRoundId` | 无 | `uint256`（当前轮次 ID） |
| 10 | `getRoundStatus` | `uint256 roundId` | `RoundStatus` enum |

### Round struct 字段

```solidity
struct Round {
    uint256 id;
    address token;       // address(0) = ETH
    uint256 ticketPrice;
    uint256 maxTickets;  // 0 = unlimited
    uint256 startTime;
    uint256 endTime;
    uint256 totalTicketsSold;
    uint256 prizePool;
    uint256 requestId;   // VRF requestId
    uint32  numWinners;
    RoundStatus status;  // 0=OPEN, 1=DRAWING, 2=COMPLETED, 3=CANCELLED
    bool    prizesClaimable;
}
```

### 关键事件

| 事件名 | 关键参数 |
|--------|----------|
| `RoundCreated` | `roundId`, `token`, `ticketPrice`, `endTime`, `numWinners` |
| `TicketsPurchased` | `roundId`, `buyer`, `numTickets`, `totalCost`, `referralCode` |
| `DrawRequested` | **`roundId`**, **`requestId`** |
| `DrawCompleted` | **`roundId`**, **`requestId`**, **`randomWords`**, **`winners`**, **`payouts`** |
| `RoundCancelled` | `roundId` |
| `PrizeClaimed` | `roundId`, `winner`, `amount` |
| `RefundClaimed` | `roundId`, `player`, `amount` |

### 哪个事件里有 requestId / winner / payout / randomWord

| 要找的字段 | 在哪个事件 |
|-----------|-----------|
| **`requestId`** | `DrawRequested`（参数 2）、`DrawCompleted`（参数 2） |
| **`randomWord`** | `DrawCompleted` → `randomWords` 是 `uint256[]`，取 `randomWords[0]` |
| **`winner`** | `DrawCompleted` → `winners` 是 `address[]` |
| **`payout`** | `DrawCompleted` → `payouts` 是 `uint256[]`，与 `winners` 一一对应 |

### 常见 revert reason

| 场景 | revert |
|------|--------|
| 轮次未开始 | `"Not started"` |
| 轮次已结束 | `"Round ended"` |
| ETH 金额不对 | `"Wrong ETH amount"` |
| 超过最大票数 | `"Exceeds max tickets"` |
| 轮次未结束就抽奖 | `"Round not ended"` |
| 不是中奖者或已领取 | `"Not a winner or already claimed"` |
| 重复退款 | `"Already refunded"` |
| VRF 还没超时就重试 | `"VRF timeout not reached"` |
| 合约暂停中 | `Pausable: paused` |
| 轮次状态不对 | `"Not open"` |

## 前端调用流程示例

```typescript
// 1. 查看所有轮次
const roundId = await lottery.currentRoundId();
const round = await lottery.getRound(roundId);

// 2. 买票（ETH 轮次）
await lottery.buyTicket(roundId, 5, ethers.ZeroHash, {
  value: round.ticketPrice * 5n,
});

// 3. 买票（带推荐码）
const refCode = ethers.keccak256(ethers.toUtf8Bytes("MYCODE"));
await lottery.buyTicket(roundId, 1, refCode, { value: ticketPrice });

// 4. 监听抽奖完成，获取 winners + payouts + randomWord
lottery.on("DrawCompleted", (roundId, requestId, randomWords, winners, payouts) => {
  console.log("randomWord:", randomWords[0]);
  console.log("winners:", winners);
  console.log("payouts:", payouts);
});

// 5. 中奖者领奖
if (await lottery.canClaimPrize(roundId, userAddress)) {
  await lottery.claimPrize(roundId);
}

// 6. 推荐系统
await referral.registerReferral(ethers.keccak256(ethers.toUtf8Bytes("MYCODE")));
const pending = await referral.getPendingCommission(myAddress, ethers.ZeroAddress);
if (pending > 0) await referral.claimCommission(ethers.ZeroAddress);
```

## 部署说明

部署顺序：
1. Treasury（1 号负责）→ 拿到地址
2. VRFConsumer（1 号负责）→ 拿到地址
3. Referral（本合约）
4. Lottery（本合约）→ 构造函数需要 VRFConsumer 和 Treasury 地址
5. 调用 `lottery.setReferral(referralAddress)` + `referral.setLottery(lotteryAddress)` 双向绑定
6. **关键**：调用 `vrfConsumer.setConsumerAuthorization(lotteryAddress, true)` 授权 Lottery 请求随机数

部署命令：
```bash
forge script script/DeployLottery.s.sol --rpc-url $SEPOLIA_RPC_URL --broadcast
```
